Valid, but not this ticket

Once the merge gate enforced review, a quieter failure surfaced: reviewers proposing good work that was not the ticket, and fixing it the only legal response. This is how findings gained a scope, deferral gained teeth, and deliveries started leaving a record of what they cost.

The ratchet

A gate that counts findings makes every suggestion scope

The merge gate now refuses to run until the exact candidate has a green review, which is where Prose, not policy ends. That worked, and it exposed the next problem: findings carried severity and routing but no way to say “valid, but not this ticket.” The rule that made that bite sits upstream of the gate: the execution skill may finalize a green review only at unanimous approval with zero unresolved actionable findings, and the evidence recorder rejects a manifest carrying any. With the gate accepting nothing but a green review, a reviewer’s “also handle this case” left one legal move: build it.

Each round of fixes produced new diff, and the next round reviewed that diff fresh. A review loop with no vocabulary for deferral has no definition of convergence beyond unanimity, and unanimity kept moving.

The scope axis

Every finding is judged against the delivery contract

Findings now carry a second axis beside severity: in contract, adjacent, or expansion, judged against what the ticket actually promised. Reviewer personas propose a classification; the synthesis step owns the final call, and on disagreement it keeps the more in-contract reading, so scope cannot quietly drift outward.

Deferral with teeth

A finding leaves the delivery only by becoming a ticket

Deferral is deliberately narrow. A defect the delivery introduced always blocks: severity outranks scope, and no classification softens a P0 or P1. Only low-severity expansion findings qualify, and an independent scope check confirms each candidate, because the orchestrator that wrote the code should not grade its own scope unchallenged.

Deferral is also not deletion. A deferred finding resolves only through an actually filed tracker issue, and the evidence recorder rejects any deferral that is blocking, high-severity, not an expansion, or missing a tracker-shaped issue id.

The sharpest correction from the work’s own review: the first cut stated all of this as prose the orchestrator could ignore by setting one boolean. The manifest now carries each finding’s severity and scope, and the recorder checks the eligibility rule itself. A rule the same agent both authors and is judged by has to be enforced by something that agent does not write.

Durable telemetry

Every delivery now leaves a durable record of its cost

It did not before. The run ledger was gitignored and overwritten every run, obligation records lived in Git-private per-worktree storage, and reviewer artifacts in temporary directories. Since every ticket starts in a fresh worktree, no artifact could answer a basic question: how has the cost of delivering been moving?

Now each passing gate run can be promoted into a tracked corpus, one file per run so parallel worktrees never conflict, recording iterations, finding counts, deferrals, and a self-reported review cost. The corpus is registered as neutral for both review evidence and freshness fingerprints, which breaks an otherwise circular dependency: recording a run must not invalidate the review evidence it describes.

Cost is kept agent-agnostic on purpose: a unit, a total, and who reported it, never converted between units. The run summary withholds a trend delta when the last run metered a different unit, and says so, rather than manufacturing a comparison.

The gate holds it

The record became the gate’s third obligation

The merge gate already models its prerequisites as typed obligations, so this needed no new machinery: telemetry.recorded joined review.green and documentation.current as a live obligation. It activates only at a size worth measuring, the same changed-line threshold as the solution-note policy. An interactive human may waive it for a single run; agents cannot, since silently skipping the record is the exact failure the obligation exists to prevent, and CI enforces it independently.

Self-correction

What the rule got wrong before it got it right

The first cut fired on any deliverable change with no waiver at all, which made the bookkeeping obligation stricter than the review obligation: a human fixing one line would have owed a fifteen-minute merge gate purely to emit a record. An obligation whose remedy is expensive needs a size threshold and a human escape hatch, or it taxes exactly the contributors it was not aimed at.

The freshness rule then deadlocked the process that satisfies it. Any deliverable edit staled the record, and the gate refused the very run that would produce a fresh one; the only escape was to fabricate exactly the misreported telemetry the rule existed to prevent. The fix keys local leniency on whether a passing run has completed for this deliverable, while CI stays unconditional. The precondition had gone in without first tracing the loop that would clear it.

And extending waivers to live obligations exposed a latent bug: the waiver flag was honored by code that never received the inputs a waiver needs, so it had been silently inert, hidden because the one live obligation declared it off. The fix routed both paths through one shared function, added a registry invariant so the flag and the allowed outcomes cannot disagree, and covered the full cross-product of obligation kind, waiver policy, and caller. A configuration flag is only real where the code that reads it runs.

Candid limits

What this does not promise

Scope discipline changes what the gate demands, not what people do with the freedom. The system records honest facts and leaves judgment where it was.

  • Review cost is self-reported by the agent harness that ran the review, not independently metered.
  • A deferred finding is only as good as the follow-up ticket’s afterlife; filing is enforced, finishing is not.
  • The scope call is a judgment against the contract; the machine checks eligibility, not wisdom.
  • The activation threshold means small deliveries leave no record; the trend describes substantial work only.

Evidence reviewed

The discipline is visible in its own artifacts

This account is grounded in what the work left behind, including the corrections its own review forced.

  • The harness solution note recording the scope axis, the deferral rules, and the three corrections, written the day the work landed.
  • The gate registry and evidence recorder: the third obligation, the deferral checks, and the telemetry validation.
  • The review and execution skills that judge scope at synthesis and pass the delivery contract into review.
  • The tracked telemetry corpus itself, whose first record describes the delivery that introduced it.
